# NutriDelightProject

A small React + TypeScript app scaffolded with Vite.

## Tech stack
- React
- TypeScript
- Vite

## Prerequisites
- Node.js 16+ (or newer)
- npm, yarn, or pnpm

## Install
Using npm:

```bash
npm install
```

Or using yarn:

```bash
yarn
```

Or using pnpm:

```bash
pnpm install
```

## Run (development)

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
